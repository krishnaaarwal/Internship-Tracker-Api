# Internship Tracker API

A Spring Boot application for tracking internship applications.

## Features
- CRUD operations for Users, Companies, Internships, and Applications
- JPA relationships between entities
- REST API endpoints
- Status tracking for applications

## Tech Stack
- Java 17
- Spring Boot 3.x
- Spring Data JPA
- H2 Database (in-memory)
- Maven

## Project Structure
Standard Spring Boot layered architecture with entities, repositories, services, and controllers.

## Learning Journey
This is my first Spring Boot project where I'm learning:
- JPA/Hibernate relationships (@OneToMany, @ManyToOne)
- Proper database design
- REST API development
- DTO pattern for data transfer
